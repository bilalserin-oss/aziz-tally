Install on a Chromebook

  1. 1

    Open it

    Press Open on Chromebook above. Aziz Tally opens in Chrome and is ready to count.

  2. 2

    Install

    Press Install app in the top-right corner of Aziz Tally, then Install. If it isn't there, use the install icon at the right end of Chrome's address bar.

  3. 3

    Pin it

    Aziz Tally opens in its own window and its icon is in the Launcher. Right-click its icon on the shelf and choose Pin so it's always there.

Use the Chromebook signed in to its usual Google account, not as a Guest: Guest mode deletes everything when it signs out. The counts are kept in Chrome on that Chromebook, so don't clear Chrome's browsing data for this site.

Install on Windows

  1. 1

    Download

    Press Download for Windows. Aziz Tally Setup.zip goes into your Downloads folder.

  2. 2

    Unzip

    Right-click Aziz Tally Setup.zip, choose Extract All, then press Extract.

  3. 3

    Run the setup

    Double-click Aziz Tally Setup.exe. If a blue box says Windows protected your PC, click More info, then Run anyway. Windows shows this for new apps from small makers.

  4. 4

    Install

    Click Install. Aziz Tally opens by itself, and its icon is on the desktop and in the Start menu.

Using it

Add 1
Tap anywhere on the screen, or press Space.
Take 1 off
Press Backspace, or open the log and press Undo last press.
Start again from 0
Reset in the top-left corner. It asks first, so a stray tap can't wipe the count.
See every press
The small LOG tab on the right edge lists each press with its time.
A new day
At midnight the count starts again from 0 by itself. Yesterday's count is kept.
Bring back an old count
Press the gear (Settings), pick the day, then press Restore. This also undoes a Reset pressed by mistake.
If the laptop shuts down
Open Aziz Tally again. It carries on from the last number, because every press is saved as it happens.
Screen stays on
While the app is open the screen won't turn off. You can switch this off in Settings.

If a button doesn't work, open this page in Chrome (or Edge on Windows) on the laptop itself, not inside a messaging app.
